# PRD — Référentiels comptables (Phase 2)

Importer ou mocker par société les comptes du plan comptable, les sections analytiques, tiers/fournisseurs, journaux et historique comptable utile à l’analyse. Les codes de comptes sont des chaînes. Une proposition ne peut utiliser qu’un compte/journal/tiers présent dans le référentiel de cette société.

La synchronisation avec une base Sage réelle reste différée jusqu’à l’inspection du fichier `.mae`, de la version Sage et des possibilités de connexion.
