# Documents facture et workflow IA (Phases 3–5)

Le module Documents est intégré au workspace Factures. `InvoiceController` gère l’intake privé, l’historique, l’aperçu/téléchargement protégé, le détail à la demande, la correction d’extraction et les relances. `ProcessInvoiceOcr`, `ExtractInvoiceData` et `AnalyzeAccountingProposal` sont des jobs tenant-scoped sur la file `ocr`.

La liste de `/invoices` ouvre la page dédiée `/companies/{company}/invoices/{invoice}`. `InvoiceDocumentViewer` montre le PDF/image original avec zoom, ajustement, rotation des images, plein écran et navigation PDF ; la rotation PDF native dépend du navigateur. À côté, `InvoiceReviewPanel` conserve la revue et les actions de proposition, permet d’éditer les champs fournisseur/client, métadonnées, lignes, totaux et informations bancaires. Sur petits écrans les deux colonnes s’empilent ; leurs panneaux défilent séparément sur desktop.

OCR.space Free Engine 3 est le défaut. La transcription est conservée dans `ocr_text`, séparément de `ocr_response`. L’extraction structurée par OpenRouter utilise le modèle configurable `qwen/qwen-2.5-7b-instruct:free` par défaut ; le JSON Schema est strict et Laravel normalise/valide les résultats. La sortie attend uniquement le JSON et ne contient aucun raisonnement, explication ou calcul. Les appels OCR, extraction et proposition utilisent des configurations distinctes. Mistral reste sélectionnable pour fournir directement les données structurées ; les propositions comptables utilisent toujours le modèle séparé `openrouter/free`.

Une relance d’extraction utilise le `ocr_text` déjà enregistré et ne redispatche pas OCR. Les réponses mal formées, hors schéma ou safety-classifier sont refusées ; les extractions précédentes valides restent intactes en cas d’échec. Les contrôles de complétude et de totaux sont déterministes et séparés du LLM. L’utilisateur autorisé peut enregistrer les champs facture, corriger les lignes comptables, rejeter sans écriture ou valider explicitement pour créer une écriture liée à la facture. Les utilisateurs société en lecture seule peuvent consulter, mais pas modifier.

Routes, configuration complète, statuts, contrôles et tests : [`../invoice-processing/README.md`](../invoice-processing/README.md). Les originaux restent privés ; aperçu/détails vérifient systématiquement l’accès à la société. Aucun appel fournisseur ne vient du navigateur.
